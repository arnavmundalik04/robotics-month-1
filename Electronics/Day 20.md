Git and GitHub
Git is the most widely used version control system used in the world. It tracks all the versions of a file and the changes made in that file over a period. 
 Working directory: The main workspace where you make changes to your files holding the current state of your project that Git hasn’t been told to track. 
The Staging area: The space where you make changes to your files before committing them.
Local repository: Project’s history stored on your computer. 
Remote repository: Version of your project on the internet where others can collaborate on it. 
Branches: Parallel features of your project: They allow you to make changes on different aspects of your project until you are ready to merge them together. 
Pull request: Way to propose changes from one branch to another. 
Merging: Process of integrating changes from one branch to another. 

Basic Git commands: https://docs.github.com/en/get-started/using-git/about-git#basic-git-commands

git init — create a local repository.
git add — stage changes.
git commit — save a snapshot.
git push — upload commits to GitHub.
git log — inspect your history.
